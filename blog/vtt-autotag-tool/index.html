vtt-Autotag-Tool python script for Descript exported subtitle .vtt files

Britta Bitrat - 22 April, 2025

Apps like Descript, when you export .vtt subtitle files, will not tag the speakers on every 42 character line output, they only voice tag on speaker changes. This does not currently allow podcasting distributors like Pinecast to recognize the speakers and format the transcript accordingly. These platforms expect speaker tagging on ALL separate 42 character subtitle lines. For a Disability podcast like Disability Disrupters that must have captions and transcriptions available for each Episode, this missing feature for Descript is a major manual time waster for me, per Episode. Here’s where I lodged the bug report with Descript in August 2024, before solving it with my janky python script - upvote if you agree that Descript should solve this, so we don’t have to do these crazy script hacks.

This python script has made my 1-2 hour manual voice tag process a 5 minute process, which is why I am sharing this.

NOTE: this python script is supplied, as is (it works for me, feel free to modify it for your own use)

Pre-Requisites

  • The Descript speakers in the transcript before Export, need to already be labelled <v SPEAKERNAME>
    • the python script looks for <v SPEAKERNAME> to add speaker tags to the .vtt file where they are missing, this made the python script simpler for me to construct than pure speaker names
    • Basically, when you import speaker audio into Descript and transcribe, name that speaker from the get-go <v SPEAKERNAME>
  • Install python on your PC (one-time setup)
  • Create a vtt-Autotag folder and add the vtt-Autotag-Tool.py script there
  • Macrons are not processed well - note what line in the file those are (as ? characters) and add back in after processing
  • Add your .vtt file (exported from Descript - with 42 character setting) into the same folder as the vtt-Autotag-Tool.py script
    • rename your .vtt input file to IN-Epx.vtt (this is what the python script expects - modify your script to suit your own workflow)
  • run the python script from the same folder that the IN-Epx.vtt is in
    • py .\vtt-AutoTag-Tool.py
      • NOTE: If you get an error, you might have macrons/non utf-8 unicode in your text - change the encoding type in the script
  • The output .vtt file will be called OUT-Epx.vtt. This is what you can upload as a Pinecast transcript
  • Add macrons back in

vtt-AutoTag-Tool.py script

The python script and a test .vtt file (an actual Descript .vtt exported file that shows the issue the script will solve) can be downloaded from my repository on github

"""
One-step VTT prep for the Disruptors podcast transcripts.
 
Replaces the old three-step workflow that was corrupting macrons:
    1. open in LibreOffice Writer, delete the Descript NOTE line
    2. Find & Replace ">: " -> ">"
    3. run the auto-tag script
 
Step 1-2 in Writer were the problem: saving a .vtt out of a WORD PROCESSOR
re-encodes it through your system codepage (usually Windows-1252), and macrons
(ā ē ī ō ū) don't exist in that codepage, so they were being flattened to "?".
This script does all three edits in Python with UTF-8 in and UTF-8 out, so the
macrons and ellipses (…) survive untouched. LibreOffice is no longer in the loop.
 
Usage:
    python3 vtt_autotag.py
        -> tags EVERY *.vtt in the current folder, writing "<name> - tagged.vtt"
           (skips files already ending in " - tagged.vtt")
 
    python3 vtt_autotag.py "Episode 26.vtt"
        -> writes "Episode 26 - tagged.vtt"
 
    python3 vtt_autotag.py "in.vtt" "out.vtt"
        -> explicit input and output
"""
 
import glob
import os
import re
import sys
 
OUT_SUFFIX = " - tagged.vtt"
 
DEFAULT_TAG = "<v Speaker>"
TAG_RE = re.compile(r"^<v[^>]*>")     # a voice tag at the start of a line
TS_RE = re.compile(r"^\d{2}:\d{2}")    # a cue-timing line
 
 
def strip_descript_note(text):
    """Remove the 'NOTE\\nThis file was generated by Descript ...' block."""
    return re.sub(
        r"^NOTE\r?\n[^\r\n]*[Dd]escript[^\r\n]*\r?\n(\r?\n)?",
        "",
        text,
        flags=re.MULTILINE,
    )
 
 
def strip_tag_colon(text):
    """Replace '<v Name>: ' with '<v Name>' (your old Find & Replace of '>: ')."""
    return text.replace(">: ", ">")
 
 
def fill_tags(lines, default_tag=DEFAULT_TAG):
    """Carry the last-seen speaker tag onto untagged continuation cues."""
    current_tag = default_tag
    out = []
    prev_was_timestamp = False
    for line in lines:
        if TS_RE.match(line):
            prev_was_timestamp = True
            out.append(line)
            continue
        if prev_was_timestamp:
            m = TAG_RE.match(line)
            if m:
                current_tag = m.group(0)
                out.append(line)
            else:
                out.append(current_tag + line)
        else:
            out.append(line)
        prev_was_timestamp = False
    return out
 
 
def tag_one(in_file, out_file):
    # Strict UTF-8. If Descript ever changes and this raises UnicodeDecodeError,
    # fix the source encoding — never add errors='replace', it destroys macrons.
    with open(in_file, "r", encoding="utf-8") as f:
        text = f.read()
    text = strip_descript_note(text)
    text = strip_tag_colon(text)
    fixed = fill_tags(text.splitlines(keepends=True))
    with open(out_file, "w", encoding="utf-8", newline="") as f:
        f.writelines(fixed)
    print(f"  {in_file}  ->  {out_file}  ({len(fixed)} lines)")
 
 
def default_out(in_file):
    return os.path.splitext(in_file)[0] + OUT_SUFFIX
 
 
def main():
    args = sys.argv[1:]
 
    if len(args) >= 2:
        # explicit input + output
        tag_one(args[0], args[1])
        return
 
    if len(args) == 1:
        # one input, auto-named output
        tag_one(args[0], default_out(args[0]))
        return
 
    # no args: tag every .vtt in the current folder
    inputs = [f for f in sorted(glob.glob("*.vtt")) if not f.endswith(OUT_SUFFIX)]
    if not inputs:
        sys.exit("No .vtt files found in this folder. "
                 "Put this script next to your transcripts, or pass a filename.")
    print(f"Tagging {len(inputs)} file(s):")
    for in_file in inputs:
        tag_one(in_file, default_out(in_file))
 
 
if __name__ == "__main__":
    main()
